SimplyScripts / IMSDb host screenplay drafts (often shooting scripts, not final-air dialogue). Forever Dreaming / Subslikescript / 8FLiX are episode dialogue transcripts, closer to what actually aired. None of these are guaranteed accurate or officially licensed — verify, don't assume.
Loads a reference transcript (from Transcribe, or any timed .vtt/.srt) and flags captions whose text diverges significantly from what the reference has for the same timespan. This flags a DISAGREEMENT, not a confirmed error — the reference transcript can itself be wrong (ASR mishears things constantly), especially on names. Treat every flag as "these two disagree, a human should check," never as "the caption is wrong."
