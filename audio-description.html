Detection settings

Runs entirely in your browser — silence detection uses the Web Audio API, scene descriptions use an open image-captioning model (one-time download, cached after). Nothing is uploaded anywhere.
Read this before you rely on it: the description model was trained on generic photos, not film — it can't recognize characters by name, can't track action across time (it only sees one freeze-frame per gap), and has no sense of what's dramatically worth describing. Expect it to produce plain, sometimes-wrong photo captions ("a person standing in a room"), not professional audio description. Every line here needs a human rewrite — this tool exists to find *where* description is needed and give you a rough starting point, not to write the final script.
