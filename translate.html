Runs entirely in your browser using open Helsinki-NLP OPUS-MT models — nothing is uploaded except the one-time model download per language (cached after that, so later runs don't need it again).
Before you trust this for delivery: these are general-purpose open translation models, not tuned for broadcast captioning or Latin-American-specific Spanish — expect real errors, especially with names, slang, and idioms. Treat the output as a first draft to review, the same way Transcribe's output is a draft. Timecodes and positioning are copied through untouched; only the dialogue text is translated, and any leading "NAME:" speaker ID is preserved as-is rather than translated.
